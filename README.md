# Ege On Air

Ege On Air is a Turkish, dark themed citizen journalism simulator built with React and Vite. It includes a simulated reporter login, a fictional newsroom dashboard, a templated story submission flow, and a profile with reputation progression. Story and profile progress is stored in browser localStorage.

## Run locally

```sh
npm install
npm run dev
```

## Build for static hosting

```sh
npm run build
```

The static site is generated in `dist/`. It can be hosted on GitHub Pages, Netlify, or another static host. This demo does not use real authentication, a database, or a news API. All sample articles are fictional.
